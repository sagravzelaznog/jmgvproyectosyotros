📐 Desarrollo del Concepto 20 min

1. ¿Qué es una Función en Programación?

En matemáticas, $f(x) = 450x + 18000$. Metes una $x$, sale un número. En programación, declaras function calcularPresupuesto(x), recibe un dato, procesa la misma ecuación y hace un return (devuelve) el resultado al usuario.

2. Manipulación del DOM (Document Object Model)

Para que la función sepa qué $x$ usar, debe "leer" el número que el usuario escribió en la caja de texto (un <input>). Y para mostrar la $y$ (el costo), debe escribir el resultado en otra caja. Esta conexión entre matemática y pantalla se llama DOM.

3. Estandarización de Variables

En ingeniería de software, a las variables no se les llama solo $x$ o $y$. Se les llama metrosZanja y costoTotal. Usar nombres descriptivos evita desastres en proyectos grandes.
