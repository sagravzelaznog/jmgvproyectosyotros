Regla de los Cuatro Pasos II

Consolidando el cálculo por definición y sus implicaciones algebraicas.

💡 TIP MAESTRO (1983): Divide al salón en 4 grupos. Para calcular la derivada de f(x)=1/x, que el Grupo 1 haga el paso 1, pase el papel al Grupo 2 para el paso 2, y así sucesivamente. ¡Gamificación instantánea física!

🎯 Propósito Formativo

Consolidar la habilidad de calcular derivadas por definición (Regla de los 4 pasos) enfrentando funciones que implican mayores retos algebraicos (como funciones racionales o polinomios de grado superior), entendiendo matemáticamente qué significa simplificar el incremento $\Delta x$ o $h$.

📖 Teoría: El Álgebra del Cambio

En la sesión anterior aprendimos el algoritmo. Sin embargo, cuando la función es más compleja, por ejemplo f(x) = 1/x, el álgebra en los pasos 2 y 3 se vuelve el verdadero desafío.

El objetivo siempre es el mismo: eliminar la "h" del denominador para evitar la división entre cero al aplicar el límite en el Paso 4. Esto a menudo requiere sumar fracciones algebraicas, aplicar binomios al cuadrado/cubo o racionalizar.

🏃 Carrera de Relevos: Los 4 Pasos

Derivaremos la función racional f(x) = 1/x. Presiona cada botón para que el siguiente "corredor" realice su paso algebraico.

Meta: Derivar f(x) = 1 / x
1. Sustituir (x+h):
f(x+h) = 1 / (x+h)
2. Restar f(x):
[1 / (x+h)] - [1 / x]
Mínimo común múltiplo...
= [x - (x+h)] / [x(x+h)]
= [x - x - h] / [x(x+h)]
= -h / [x(x+h)]
3. Dividir entre h:
( -h / [x(x+h)] ) / h
Se cancelan las "h"...
= -h / [h * x(x+h)]
= -1 / [x(x+h)]
4. Límite h → 0:
lim -1 / [x(x + 0)]
= -1 / (x * x)
f'(x) = -1 / x² 🏁
