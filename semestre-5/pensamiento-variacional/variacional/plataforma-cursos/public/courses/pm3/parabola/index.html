Análisis de la Parábola

Estudia las ecuaciones y calcula los elementos fundamentales (Vértice, Foco, Lado Recto y Directriz).

Zona de Estudio: Biblioteca de Fórmulas

Ecuación Ordinaria

Eje Vertical (Abre Arriba/Abajo)
$$(x - h)^2 = 4p(y - k)$$
Eje Horizontal (Abre Der/Izq)
$$(y - k)^2 = 4p(x - h)$$

Ecuación General

Eje Vertical (Polinomio en x)
$$Ax^2 + Dx + Ey + F = 0$$
Eje Horizontal (Polinomio en y)
$$Cy^2 + Dx + Ey + F = 0$$

Ecuación Paramétrica

Forma estrictamente polinomial, donde $t$ es el parámetro independiente.

Vértice en el Origen $V(0,0)$
$$x = 2pt$$
$$y = pt^2$$
Vértice Desplazado $V(h,k)$
$$x = h + 2pt$$
$$y = k + pt^2$$

Cálculo de Elementos

  • Vértice $$V(h, k)$$
  • Lado Recto (Ancho Focal) $$LR = \vert 4p \vert$$
  • Parámetro (Distancia Focal) $$p = \frac{LR}{4} \ \text{(con signo)}$$
