1. Identidades Fundamentales +

Identidades Recíprocas

$$\sin \theta = \frac{1}{\csc \theta}$$
$$\cos \theta = \frac{1}{\sec \theta}$$
$$\tan \theta = \frac{1}{\cot \theta}$$

Identidades de Cociente

$$\tan \theta = \frac{\sin \theta}{\cos \theta}$$
$$\cot \theta = \frac{\cos \theta}{\sin \theta}$$

Identidades Pitagóricas

$$\sin^2 \theta + \cos^2 \theta = 1$$
$$1 + \tan^2 \theta = \sec^2 \theta$$
$$1 + \cot^2 \theta = \csc^2 \theta$$
2. Ángulo Doble y Mitad +

Ángulo Doble

$$\sin 2\theta = 2 \sin \theta \cos \theta$$
$$\cos 2\theta = \cos^2 \theta - \sin^2 \theta$$
$$\tan 2\theta = \frac{2 \tan \theta}{1 - \tan^2 \theta}$$

Ángulo Mitad

$$\sin \frac{\theta}{2} = \pm \sqrt{\frac{1 - \cos \theta}{2}}$$
$$\cos \frac{\theta}{2} = \pm \sqrt{\frac{1 + \cos \theta}{2}}$$
$$\tan \frac{\theta}{2} = \frac{1 - \cos \theta}{\sin \theta}$$
3. Suma y Resta de Ángulos +

Suma de Ángulos

$$\sin(A+B) = \sin A \cos B + \cos A \sin B$$
$$\cos(A+B) = \cos A \cos B - \sin A \sin B$$
$$\tan(A+B) = \frac{\tan A + \tan B}{1 - \tan A \tan B}$$

Resta de Ángulos

$$\sin(A-B) = \sin A \cos B - \cos A \sin B$$
$$\cos(A-B) = \cos A \cos B + \sin A \sin B$$
$$\tan(A-B) = \frac{\tan A - \tan B}{1 + \tan A \tan B}$$
4. Producto a Suma y Viceversa +

Producto a Suma

$$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$
$$\cos A \cos B = \frac{1}{2}[\cos(A+B) + \cos(A-B)]$$
$$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$

Suma a Producto

$$\sin A + \sin B = 2 \sin\left(\frac{A+B}{2}\right) \cos\left(\frac{A-B}{2}\right)$$
$$\sin A - \sin B = 2 \cos\left(\frac{A+B}{2}\right) \sin\left(\frac{A-B}{2}\right)$$
$$\cos A + \cos B = 2 \cos\left(\frac{A+B}{2}\right) \cos\left(\frac{A-B}{2}\right)$$
$$\cos A - \cos B = -2 \sin\left(\frac{A+B}{2}\right) \sin\left(\frac{A-B}{2}\right)$$
5. Aplicaciones +

Resolución de Ecuaciones Trigonométricas

Resolver: $\sin x + \cos x = 1$

Paso 1: Elevar al cuadrado ambos lados
$$(\sin x + \cos x)^2 = 1^2$$
Paso 2: Desarrollar y simplificar
$$\sin^2 x + 2 \sin x \cos x + \cos^2 x = 1$$
Paso 3: Usar identidad pitagórica
$$1 + \sin 2x = 1 \Rightarrow \sin 2x = 0$$

Integración de Funciones Trigonométricas

Calcular: $\int \sin^2 x \, dx$

$$\sin^2 x = \frac{1 - \cos 2x}{2}$$
$$\int \sin^2 x \, dx = \frac{1}{2} \int (1 - \cos 2x) \, dx = \frac{x}{2} - \frac{\sin 2x}{4} + C$$
