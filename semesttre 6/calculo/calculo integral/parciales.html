Resolución de Integral: Problema de Valor Inicial

Este módulo auto-explicativo muestra la solución paso a paso de la integral usando fracciones parciales, incluyendo la evaluación de la constante \(c\).

$$\int x' = \int -\frac{3y^2 - 12y + 3}{(2-y)^2(y+1)} dy$$

Usa los botones en la parte inferior para avanzar de manera interactiva.

1 Planteamiento de Fracciones Parciales

Descomponemos el denominador en fracciones de acuerdo a sus factores (uno repetido y uno distinto).

$$-\frac{3y^2 - 12y + 3}{(2-y)^2(y+1)} = \frac{A}{2-y} + \frac{B}{(2-y)^2} + \frac{C}{y+1}$$
2 Desarrollo del Numerador

Multiplicamos cruzado para encontrar un denominador común y expandimos los términos.

$$A(2-y)(y+1) + B(y+1) + C(2-y)^2$$ $$= A(2y + 2 - y^2 - y) + B(y+1) + C(4 - 4y + y^2)$$ $$= y^2(-A + C) + y(A + B - 4C) + (2A + B + 4C)$$
3 Sistema de Ecuaciones

Igualamos los coeficientes obtenidos con el numerador original: \(-3y^2 + 12y - 3\).

\( y^2 \):    \( -A + C = -3 \)
\( y \):      \( A + B - 4C = 12 \)
Cte:    \( 2A + B + 4C = -3 \)
4 Resolución del Sistema

Resolviendo el sistema lineal por sustitución:

\( C = A - 3 \)
\( A + B - 4(A - 3) = 12 \implies -3A + B = 0 \implies B = 3A \)
\( 2A + 3A + 4(A - 3) = -3 \implies 9A = 9 \implies \mathbf{A = 1} \)
\( B = 3(1) \implies \mathbf{B = 3} \)
\( C = 1 - 3 \implies \mathbf{C = -2} \)
5 Integración (Solución General)

Sustituimos y resolvemos las integrales resultantes. Como \(x' = dx/dy\), integramos respecto a \(y\).

\( \int dx = \int \left( \frac{1}{2-y} + \frac{3}{(2-y)^2} - \frac{2}{y+1} \right) dy \)

\( \int \frac{1}{2-y} dy = -\ln(2-y) \)
\( \int 3(2-y)^{-2} dy = \frac{3}{2-y} \)
\( \int \frac{-2}{y+1} dy = -2\ln(y+1) = -\ln((y+1)^2) \)

Solución General:
\( x = \frac{3}{2-y} - \ln(2-y) - \ln((y+1)^2) + c \)
6 Evaluación de la Condición Inicial

Se nos proporciona el punto \((-\ln 4, 1)\), lo que significa que \(x = -\ln 4\) cuando \(y = 1\). Sustituimos estos valores para encontrar \(c\).

\( -\ln 4 = \frac{3}{2-1} - \ln(2-1) - \ln(1+1)^2 + c \)
\( -\ln 4 = \frac{3}{1} - \ln(1) - \ln(2^2) + c \)
\( -\ln 4 = 3 - 0 - \ln 4 + c \)

Cancelando \(-\ln 4\) de ambos lados:
\( 0 = 3 + c \implies \mathbf{c = -3} \)
7 Solución Particular Final

Sustituimos el valor de \(c\) en la ecuación general para obtener la respuesta definitiva.

$$x = \frac{3}{2-y} - \ln(2-y) - \ln(y+1)^2 - 3$$
