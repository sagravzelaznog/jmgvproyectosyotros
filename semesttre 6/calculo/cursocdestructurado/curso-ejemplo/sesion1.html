Sesión 1: Arquitectura Web Básica

Objetivo de Aprendizaje

Comprender cómo interactúan el Cliente y el Servidor mediante peticiones HTTP y renderizado del navegador.

El Modelo Cliente-Servidor

La web funciona bajo un modelo donde tu navegador (Cliente) solicita recursos y un computador remoto (Servidor) responde con archivos como HTML, CSS y JavaScript.

Frontend (Cliente)

Se encarga de la interfaz visual, interacciones del usuario y renderizado de gráficos.

Backend (Servidor)

Gestiona la lógica de negocio, base de datos, seguridad y autenticación.
