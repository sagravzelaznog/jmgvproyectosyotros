📐 Sesión 5: El Problema del Área - Sumas de Riemann

De las sumas sigma al cálculo de áreas

¡Hemos llegado al momento crucial! Las sumas que hemos estudiado se convierten en sumas de Riemann para aproximar áreas bajo curvas. Este es el puente que nos lleva del álgebra al cálculo integral.

🎯 El Problema del Área

¿Cómo calcular el área bajo una curva?

Desde la antigüedad, los matemáticos se preguntaron:

  • ¿Área de un triángulo? Fácil: base × altura / 2
  • ¿Área de un círculo? Complicado: πr²
  • ¿Área bajo una curva irregular? ¡Imposible con geometría simple!

Solución: Dividir la curva en rectángulos pequeños y sumar sus áreas.

El problema: Calcular ∫ f(x) dx de a a b
Nuestra aproximación: Σ f(xᵢ) Δx

¡Esta es exactamente la idea de las sumas de Riemann!

📊 Sumas de Riemann: La Idea Fundamental

Definición de suma de Riemann

Para aproximar ∫ab f(x) dx:

  1. Dividir el intervalo [a,b] en n subintervalos
  2. Elegir un punto xᵢ en cada subintervalo
  3. Multiplicar f(xᵢ) por el ancho Δx
  4. Sumar todas las áreas: Σ f(xᵢ) Δx
Suma de Riemann = \(\sum_{i=1}^{n} f(x_i) \Delta x\)
donde Δx = (b - a)/n

Ejemplo: Área bajo f(x) = x² de 0 a 2

Con n = 4 subintervalos:

  • Δx = (2-0)/4 = 0.5
  • Subintervalos: [0,0.5], [0.5,1], [1,1.5], [1.5,2]
  • Elegimos punto medio: x₁=0.25, x₂=0.75, x₃=1.25, x₄=1.75
Suma = f(0.25)×0.5 + f(0.75)×0.5 + f(1.25)×0.5 + f(1.75)×0.5
= (0.0625 + 0.5625 + 1.5625 + 3.0625) × 0.5
= 5.25 × 0.5 = 2.625

Área exacta: ∫₀² x² dx = [x³/3]₀² = 8/3 ≈ 2.667

🔀 Tipos de Sumas de Riemann

Suma inferior (rectángulos inscritos)

Usa el punto más bajo de cada subintervalo:

xᵢ = punto izquierdo del subintervalo

Ventaja: Siempre subestima el área

Desventaja: Menos precisa para funciones crecientes

Suma superior (rectángulos circunscritos)

Usa el punto más alto de cada subintervalo:

xᵢ = punto derecho del subintervalo

Ventaja: Siempre sobreestima el área

Desventaja: Menos precisa para funciones decrecientes

Suma media (rectángulos intermedios)

Usa el punto medio de cada subintervalo:

xᵢ = punto medio del subintervalo

Ventaja: Generalmente más precisa

Base: De las técnicas de integración numérica

🔗 Conexión con lo que ya sabemos

Las sumas de Riemann SON sumas sigma

Todo lo que hemos aprendido sobre sumas se aplica directamente:

  • Propiedades de linealidad: Σ(c·f(xᵢ)) = c·Σ f(xᵢ)
  • Separación de términos: Σ(f(xᵢ) + g(xᵢ)) = Σ f(xᵢ) + Σ g(xᵢ)
  • Factor constante: Σ k = k·n (para áreas constantes)

🎯 Aplicación directa

Una suma de Riemann para f(x) = x + 1 de 0 a 2 con n=4:

Σ ((xᵢ + 1) Δx) = Σ xᵢ Δx + Σ 1·Δx = (Σ xᵢ)Δx + n·Δx

¡Todas las propiedades que estudiamos se aplican aquí!

🚀 El Límite: Nacimiento de la Integral

¿Y si n tiende a infinito?

Cuando el número de rectángulos tiende a infinito:

\lim_{n \to \infty} \sum_{i=1}^{n} f(x_i) \Delta x = \int_a^b f(x) dx

Esto es exactamente la definición de la integral definida!

Sumas discretas → Integral continua
Áreas de rectángulos → Área bajo la curva

🔬 Aplicaciones de las Sumas de Riemann

¿Para qué sirven?

Las sumas de Riemann son la base de:

  • Cálculo de áreas irregulares - Bajo cualquier curva
  • Integración numérica - Cuando no hay antiderivada
  • Probabilidad y estadística - Esperanza matemática
  • Física e ingeniería - Trabajo, energía, momentos
  • Economía y finanzas - Cálculo de utilidades
Ejemplo: Área bajo la curva de velocidad = distancia recorrida
