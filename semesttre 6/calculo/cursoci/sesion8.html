Sesión 8: Práctica de Sumas de Riemann

Aplicación con la función f(x) = x² + 2

Refuerza tu comprensión de las sumas de Riemann aplicando tanto rectángulos inscritos como circunscritos a una función cuadrática.

📌 Recordatorio

En las sesiones anteriores aprendimos a aproximar áreas usando:

  • Sumas inferiores: Usando el valor mínimo en cada subintervalo (rectángulos inscritos)
  • Sumas superiores: Usando el valor máximo en cada subintervalo (rectángulos circunscritos)

Hoy aplicaremos ambos métodos a la función f(x) = x² + 2.

🎯 Ejemplo Guiado

Vamos a calcular el área bajo la curva de f(x) = x² + 2 en el intervalo [1, 3] usando 4 subintervalos.

Paso 1: Dividir el intervalo

Dividimos [1, 3] en 4 subintervalos iguales:

Δx = (3 - 1)/4 = 0.5

Puntos de división: x₀=1.0, x₁=1.5, x₂=2.0, x₃=2.5, x₄=3.0

Paso 2: Calcular la suma inferior (rectángulos inscritos)

Usamos el valor mínimo de f en cada subintervalo:

L₄ = f(1.0)⋅0.5 + f(1.5)⋅0.5 + f(2.0)⋅0.5 + f(2.5)⋅0.5

L₄ = (1²+2)⋅0.5 + (1.5²+2)⋅0.5 + (2.0²+2)⋅0.5 + (2.5²+2)⋅0.5

L₄ = 3⋅0.5 + 4.25⋅0.5 + 6⋅0.5 + 8.25⋅0.5

L₄ = 1.5 + 2.125 + 3 + 4.125 = 10.75

Paso 3: Calcular la suma superior (rectángulos circunscritos)

Usamos el valor máximo de f en cada subintervalo:

U₄ = f(1.5)⋅0.5 + f(2.0)⋅0.5 + f(2.5)⋅0.5 + f(3.0)⋅0.5

U₄ = (1.5²+2)⋅0.5 + (2.0²+2)⋅0.5 + (2.5²+2)⋅0.5 + (3.0²+2)⋅0.5

U₄ = 4.25⋅0.5 + 6⋅0.5 + 8.25⋅0.5 + 11⋅0.5

U₄ = 2.125 + 3 + 4.125 + 5.5 = 14.75

Paso 4: Interpretación

El área real bajo la curva está entre 10.75 y 14.75 unidades cuadradas.

Al aumentar el número de subintervalos (n), la diferencia entre Lₙ y Uₙ disminuirá, y ambas se acercarán al área exacta.

🧩 Ejercicios Prácticos

Ejercicio 1: Cálculo Manual

Calcula manualmente la suma inferior (L₄) y superior (U₄) para f(x) = x² + 2 en el intervalo [0, 2] con 4 subintervalos.

Paso 1: Δx = (2-0)/4 = 0.5

Paso 2 (L₄): f(0)⋅0.5 + f(0.5)⋅0.5 + f(1.0)⋅0.5 + f(1.5)⋅0.5 = 2⋅0.5 + 2.25⋅0.5 + 3⋅0.5 + 4.25⋅0.5 = 5.75

Paso 3 (U₄): f(0.5)⋅0.5 + f(1.0)⋅0.5 + f(1.5)⋅0.5 + f(2.0)⋅0.5 = 2.25⋅0.5 + 3⋅0.5 + 4.25⋅0.5 + 6⋅0.5 = 7.75

Ejercicio 2: Generalización

Para f(x) = x² + 2 en [a, b] con n subintervalos, encuentra una expresión general para:

  1. El ancho de cada subintervalo (Δx)
  2. Los puntos de división x₀, x₁, ..., xₙ
  3. La suma inferior Lₙ
  4. La suma superior Uₙ

1. Ancho de subintervalo: Δx = (b - a)/n

2. Puntos de división: xᵢ = a + i⋅Δx para i = 0, 1, 2, ..., n

3. Suma inferior (Lₙ): Σᵢ₌₁ⁿ [f(xᵢ₋₁)]⋅Δx

4. Suma superior (Uₙ): Σᵢ₌₁ⁿ [f(xᵢ)]⋅Δx

Donde f(x) = x² + 2

🔍 Aplicaciones en la Vida Real

Las sumas de Riemann tienen aplicaciones en diversas áreas:

Física

Cálculo del trabajo realizado por una fuerza variable, distancia recorrida con velocidad variable, etc.

Economía

Cálculo del ingreso total cuando la tasa de ingreso varía con el tiempo.

Ingeniería

Cálculo de volúmenes, centros de masa y trabajo en sistemas con propiedades variables.
