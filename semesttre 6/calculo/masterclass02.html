Masterclass 2: Funciones

Una función es una relación especial entre dos conjuntos, llamados dominio y codominio, donde cada elemento del dominio se relaciona con exactamente un elemento del codominio.

2.1 Definición formal

Dados dos conjuntos no vacíos A y B, una función f de A en B (denotada f: A → B) es una relación que asigna a cada elemento x ∈ A un único elemento y ∈ B, llamado imagen de x mediante f.

Ejemplo 1:

Sean A = {1, 2, 3} y B = {a, b, c, d}

f = {(1,b), (2,a), (3,c)} es una función

g = {(1,a), (1,b), (2,c)} NO es función (el 1 tiene dos imágenes)

h = {(1,a), (2,b)} NO es función de A en B (falta el 3)

2.2 Notación y terminología

  • f: A → B (función f de A en B)
  • y = f(x) (y es la imagen de x mediante f)
  • Dominio (Dom f): Conjunto de partida A
  • Codominio: Conjunto de llegada B
  • Rango o recorrido: {f(x) | x ∈ A} (subconjunto de B)
  • Imagen de un elemento: f(a) es la imagen de a
  • Preimagen: Si f(a) = b, entonces a es preimagen de b

Ejemplo 2:

Sea f: ℝ → ℝ definida por f(x) = x² + 1

• f(2) = 2² + 1 = 5

• f(-1) = (-1)² + 1 = 2

• Dom f = ℝ

• Rango = [1, ∞)

2.3 Representación de funciones

Las funciones se pueden representar de varias formas:

  1. Diagrama de flechas: Muestra la relación entre elementos de los conjuntos
  2. Tabla de valores: Lista pares ordenados (x, f(x))
  3. Gráfica cartesiana: Representación en el plano xy
  4. Fórmula o ecuación: Expresión algebraica que relaciona x con f(x)

Ejercicio 1:

Dada la función f(x) = 2x - 3, calcula:

  1. f(0)
  2. f(-1)
  3. f(1/2)
  4. El valor de x tal que f(x) = 5

Ejercicio 2:

Determina cuáles de las siguientes relaciones son funciones:

  1. R₁ = {(1,2), (2,3), (3,4)}
  2. R₂ = {(1,2), (1,3), (2,4)}
  3. R₃ = {(x,y) ∈ ℝ×ℝ | y = √x}
  4. R₄ = {(x,y) ∈ ℝ×ℝ | x = y²}
