Masterclass 3: Notación de Funciones

La notación en funciones es fundamental para expresar de manera clara y concisa las relaciones matemáticas. A continuación, se presentan los aspectos más importantes de la notación funcional.

3.1 Notación básica

La notación estándar para una función es:

f: A → B

Donde:

  • f: Nombre de la función
  • A: Dominio (conjunto de partida)
  • B: Codominio (conjunto de llegada)
  • f(x): Valor de la función en x (se lee "f de x")

Ejemplo 1:

f: ℝ → ℝ definida por f(x) = 2x + 3

• f(0) = 3

• f(1) = 5

• f(a) = 2a + 3

• f(x + h) = 2(x + h) + 3 = 2x + 2h + 3

3.2 Notación alternativa

Existen diferentes formas de denotar funciones:

  • Notación de función: f(x) = x²
  • Notación de mapeo: x ↦ x²
  • Notación de conjunto: f = {(x, y) | y = x²}
  • Notación implícita: y = x²

3.3 Funciones definidas por partes

Algunas funciones se definen de manera diferente en distintos intervalos:

Ejemplo 2: Función valor absoluto

$$ |x| = \begin{cases} x & \text{si } x \geq 0 \\ -x & \text{si } x < 0 \end{cases} $$

Ejercicio 1:

Dada la función f(x) = 3x² - 2x + 1, calcula:

  1. f(0)
  2. f(-1)
  3. f(2a)
  4. f(x + h)

Ejercicio 2:

Evalúa la siguiente función definida por partes en los valores dados:

$$ f(x) = \begin{cases} x + 2 & \text{si } x < 0 \\ x^2 & \text{si } 0 \leq x < 2 \\ 4 & \text{si } x \geq 2 \end{cases} $$

Calcula: f(-1), f(0), f(1), f(2), f(3)
