Masterclass 6: Dominio, Contradominio y Rango de una Función

Comprender estos conceptos es fundamental para el estudio de funciones. A continuación, se explican en detalle:

6.1 Dominio de una función

El dominio de una función es el conjunto de todos los valores de entrada posibles (valores de $x$) para los cuales la función está definida.

Ejemplo 1: Dominio de funciones algebraicas

  • Función polinómica: $f(x) = 2x^2 - 3x + 1$
    Dominio: $\mathbb{R}$ (todos los números reales)
  • Función racional: $g(x) = \frac{1}{x-2}$
    Dominio: $\mathbb{R} - \{2\}$ (todos los reales excepto 2)
  • Función raíz cuadrada: $h(x) = \sqrt{x+3}$
    Dominio: $[-3, \infty)$ (valores de $x$ tales que $x \geq -3$)

6.2 Contradominio (o Codominio)

Es el conjunto de valores posibles que la función puede devolver como salida. Es importante no confundirlo con el rango.

Ejemplo 2: Contradominio

Para la función $f: \mathbb{R} \rightarrow \mathbb{R}$ definida por $f(x) = x^2$:
- El contradominio es $\mathbb{R}$
- Aunque el rango es $[0, \infty)$

6.3 Rango (o Recorrido)

Es el conjunto de valores que realmente toma la función como salida.

Ejemplo 3: Determinación del rango

Para $f(x) = x^2 + 1$:
- Como $x^2 \geq 0$ para todo $x$ real
- Entonces $x^2 + 1 \geq 1$
- Por lo tanto, el rango es $[1, \infty)$

6.4 Determinación del dominio en funciones comunes

Tipo de Función Restricción del Dominio Ejemplo
Polinómica Ninguna $f(x) = x^3 - 2x + 1$
Racional Denominador ≠ 0 $f(x) = \frac{x+2}{x-3}$
Raíz par Radicando ≥ 0 $f(x) = \sqrt{4-x^2}$
Logarítmica Argumento > 0 $f(x) = \ln(x+4)$

Ejercicio 1:

Determina el dominio de las siguientes funciones:

  1. $f(x) = \sqrt{9 - x^2}$
  2. $g(x) = \frac{1}{x^2 - 4}$
  3. $h(x) = \frac{\sqrt{x-1}}{x-3}$

Ejercicio 2:

Para la función $f(x) = \frac{2x - 1}{x + 3}$:

  1. Determina su dominio
  2. Encuentra su rango
  3. ¿Cuál sería un posible contradominio para esta función?
