7.8 Función Valor Absoluto

La función valor absoluto se define como:

$$ f(x) = |x| = \begin{cases} x & \text{si } x \geq 0 \\ -x & \text{si } x < 0 \end{cases} $$

Características principales:

  • Dominio: $\mathbb{R}$ (todos los números reales)
  • Rango: $[0, \infty)$
  • Gráfica: Forma de "V" con vértice en el origen (0,0)
  • Simetría: Función par ($f(-x) = f(x)$)
  • Continuidad: Continua en todo su dominio
  • Derivabilidad: No diferenciable en $x = 0$ (tiene un "pico" en este punto)

Forma general con transformaciones:

$$ f(x) = a|b(x - h)| + k $$ donde:

  • $a$: Estiramiento/compresión vertical y reflexión
  • $b$: Estiramiento/compresión horizontal y reflexión
  • $(h, k)$: Traslación del vértice

Ejemplo 1: Análisis de $f(x) = -2|3x - 6| + 4$

Paso 1: Reescribir en forma estándar

$ f(x) = -2|3(x - 2)| + 4 $

Paso 2: Identificar transformaciones
  • Desplazamiento horizontal: 2 unidades a la derecha ($h=2$)
  • Estiramiento horizontal: factor $\frac{1}{3}$ ($b=3$)
  • Reflexión vertical: $a=-2$ (abre hacia abajo)
  • Estiramiento vertical: factor 2
  • Desplazamiento vertical: 4 unidades hacia arriba ($k=4$)
Paso 3: Características
  • Vértice: $(2, 4)$
  • Dominio: $\mathbb{R}$
  • Rango: $(-\infty, 4]$
  • Intersecciones:
    • Eje Y: $f(0) = -2|0-6|+4 = -8$ → $(0,-8)$
    • Eje X: Resolver $0 = -2|3x-6|+4$ → $x=\frac{8}{3}, \frac{4}{3}$

Propiedades del valor absoluto:

  1. $|a| \geq 0$ para todo $a \in \mathbb{R}$
  2. $|a| = 0$ si y solo si $a = 0$
  3. $|ab| = |a||b|$
  4. $\left|\frac{a}{b}\right| = \frac{|a|}{|b|}$ para $b \neq 0$
  5. Desigualdad triangular: $|a + b| \leq |a| + |b|$
  6. $|x| < a$ equivale a $-a < x < a$ para $a > 0$
  7. $|x| > a$ equivale a $x < -a$ o $x > a$ para $a > 0$

Aplicaciones prácticas:

Ejemplo 2: Distancia en la recta numérica

El valor absoluto representa la distancia entre dos puntos en la recta numérica. La distancia entre $a$ y $b$ es $|a - b|$.

Problema: Un termómetro tiene una precisión de $\pm 0.5^\circ C$. Si marca $22^\circ C$, ¿entre qué valores está la temperatura real $T$?

Solución: $ |T - 22| \leq 0.5 \\ -0.5 \leq T - 22 \leq 0.5 \\ 21.5 \leq T \leq 22.5 $ La temperatura real está entre $21.5^\circ C$ y $22.5^\circ C$.

Ejercicio 1:

Para cada función, determina:

  1. Vértice
  2. Dominio y rango
  3. Intersecciones con los ejes
  4. Gráfica

a) $f(x) = |x - 3| + 2$

b) $g(x) = -\frac{1}{2}|x + 1| - 3$

c) $h(x) = 3|2x - 4|$

Ejercicio 2:

Resuelve las siguientes ecuaciones y desigualdades con valor absoluto:

a) $|3x - 2| = 7$

b) $2|4 - x| + 5 < 11$

c) $\left|\frac{x + 1}{2}\right| \geq 3$

Ejercicio 3:

Una fábrica produce varillas de metal que deben medir exactamente 50 cm de largo. Por restricciones de producción, se permite una tolerancia de 0.1 cm.

  1. Escribe una desigualdad con valor absoluto que represente la longitud aceptable de las varillas.
  2. ¿Sería aceptable una varilla que mide 49.95 cm? ¿Y una que mide 50.12 cm?
  3. Si una varilla mide $50 + h$ cm, ¿qué valores puede tomar $h$ para que sea aceptable?
