Notación y Valor de una Función

Sesión 2 - Módulo 1: Conceptos Básicos

Objetivo de Aprendizaje:

Comprender la notación $f(x)$ y evaluar funciones en puntos específicos, sustituyendo valores numéricos y expresiones algebraicas para obtener la imagen de un elemento del dominio.

¿Qué significa $f(x)$?

La notación $f(x)$ se lee "f de x" y representa el valor de la función f cuando la variable independiente toma el valor $x$. No es una multiplicación, es una instrucción: "aplica la regla $f$ al número $x$".

Ejemplo fundamental:

Si $f(x) = 3x + 2$, entonces:

  • $f(1) = 3(1) + 2 = 5$
  • $f(-2) = 3(-2) + 2 = -4$
  • $f(a) = 3a + 2$
  • $f(x+h) = 3(x+h) + 2 = 3x + 3h + 2$

Evaluación con Expresiones Algebraicas

No solo evaluamos funciones en números: también podemos sustituir variables o expresiones completas. Esto es fundamental para el cociente de diferencias, que usarás en el Cálculo Diferencial.

Ejemplo 1: Cuadrática

Si $g(x) = x^2 - 4x + 1$

$g(3) = (3)^2 - 4(3) + 1 = 9 - 12 + 1 = -2$

$g(-1) = (-1)^2 - 4(-1) + 1 = 1 + 4 + 1 = 6$

Ejemplo 2: Racional

Si $h(x) = \dfrac{2x}{x-1}$

$h(3) = \dfrac{2(3)}{3-1} = \dfrac{6}{2} = 3$

$h(1) = \dfrac{2(1)}{1-1} = \dfrac{2}{0}$ → ¡No existe!

Cociente de Diferencias:

La expresión $\dfrac{f(x+h) - f(x)}{h}$ se llama cociente de diferencias y es la base de la derivada. Practica evaluando $f(x+h)$ para dominarlo.
