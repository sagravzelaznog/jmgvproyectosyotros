# Curso de Cálculo Integral - Plataforma Web

Una plataforma web completa para el aprendizaje del Cálculo Integral, diseñada específicamente para estudiantes de preparatoria sin conocimientos previos.

## 🚀 Cómo Usar

### Para Estudiantes

1. Abre `index.html` en un navegador web
2. Navega por las sesiones usando el menú lateral
3. Estudia el contenido teórico y ejemplos
4. Practica con los ejercicios interactivos
5. Usa las herramientas matemáticas integradas

### Para Instructores

1. El contenido está estructurado por sesiones (60 min cada una)
2. Cada sesión incluye teoría, ejemplos y práctica
3. Las evaluaciones están programadas en sesiones 21, 42 y 64
4. El sistema permite seguimiento del progreso

## 📚 Estructura del Curso

### Módulo 1: Los Fundamentos (Sesiones 1-21)

- Notación sigma y sumas
- Sumas de Riemann
- Integrales inmediatas
- Técnicas básicas de integración

### Módulo 2: Técnicas de Integración (Sesiones 22-42)

- Integración trigonométrica
- Integración por partes
- Sustitución trigonométrica
- Fracciones parciales

### Módulo 3: Aplicaciones (Sesiones 43-64)

- Teorema fundamental del cálculo
- Aplicaciones geométricas
- Ecuaciones diferenciales
- Métodos numéricos

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Diseño moderno con variables CSS y animaciones
- **JavaScript ES6+**: Funcionalidades interactivas y cálculos
- **MathJax**: Renderizado de fórmulas matemáticas
- **Canvas API**: Visualizaciones gráficas matemáticas
