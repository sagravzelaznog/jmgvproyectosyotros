🧮 Sesión 3: Propiedades de las Sumatorias

Linealidad y constantes: El poder del álgebra en las sumas

En esta sesión profundizaremos en las propiedades algebraicas de las sumas. La linealidad y el manejo de constantes nos permiten simplificar sumas complejas y sentar las bases para las técnicas de integración que veremos más adelante.

📚 Recordatorio: Propiedades Básicas

En las Sesión 2 aprendimos las propiedades fundamentales:

  • Constante: \(\sum_{i=1}^{n} c = n \times c\)
  • Factor constante: \(c \times \sum a_i = \sum (c \times a_i)\)
  • Aditividad: \(\sum (a_i + b_i) = \sum a_i + \sum b_i\)
  • Cambio de índice: \(\sum a_i = \sum a_j = \sum a_k\)

¡Ahora vamos a explorar las propiedades de linealidad que hacen que las sumas sean tan poderosas!

🔄 Propiedad de Linealidad

Linealidad: La propiedad más importante

La linealidad es la propiedad que permite manipular sumas como si fueran variables algebraicas:

\(\sum_{i=1}^{n} (a_i + b_i) = \sum_{i=1}^{n} a_i + \sum_{i=1}^{n} b_i\)

Esto significa que:

  • Podemos separar términos dentro de una suma
  • Podemos combinar sumas de la misma variable
  • La suma es distributiva respecto a la adición

Ejemplo 1: Linealidad en acción

Problema: Simplificar \(\sum_{i=1}^{4} (2i + 3i^2 - i)\)

Solución paso a paso:

  1. Agrupar términos similares:
    \(\sum_{i=1}^{4} (2i + 3i^2 - i) = \sum_{i=1}^{4} (i + 3i^2)\)
  2. Aplicar linealidad:
    \(\sum_{i=1}^{4} (i + 3i^2) = \sum_{i=1}^{4} i + 3\sum_{i=1}^{4} i^2\)
  3. Factorizar la constante:
    \(3\sum_{i=1}^{4} i^2 = 3 \times \sum_{i=1}^{4} i^2\)
  4. Calcular sumas básicas:
    \(\sum_{i=1}^{4} i = 1 + 2 + 3 + 4 = 10\)
    \(\sum_{i=1}^{4} i^2 = 1 + 4 + 9 + 16 = 30\)
  5. Resultado final:
    \(10 + 3(30) = 10 + 90 = 100\)

Verificación:

(2×1 + 3×1² - 1) + (2×2 + 3×2² - 2) + (2×3 + 3×3² - 3) + (2×4 + 3×4² - 4)
= (2+3-1) + (4+12-2) + (6+27-3) + (8+48-4) = 4 + 14 + 30 + 52 = 100 ✅

📊 Propiedades Avanzadas de Constantes

Propiedad 7: Constante elevada a potencia

Si tenemos una constante elevada a una potencia variable:

\(\sum_{i=1}^{n} c^{k} = c^{1} + c^{2} + c^{3} + \dots + c^{n}\)

Pero si la potencia es constante:

\(\sum_{i=1}^{n} c^{k} = c^{k} + c^{k} + c^{k} + \dots + c^{k}\) (k veces)
\(= k \times c^{k}\)

Ejemplo:

\(\sum_{i=1}^{3} 2^{i} = 2^{1} + 2^{2} + 2^{3} = 2 + 4 + 8 = 14\)
\(\sum_{i=1}^{3} 2^{3} = 2^{3} + 2^{3} + 2^{3} = 8 + 8 + 8 = 24\)

Propiedad 8: Constante en fracciones

Sumas que involucran constantes en fracciones:

\(\sum_{i=1}^{n} \frac{c}{i} \neq \frac{c}{n}\) ❌

¡Cuidado! La constante no se puede factorizar fuera del denominador.

\(\sum_{i=1}^{3} \frac{1}{i} = \frac{1}{1} + \frac{1}{2} + \frac{1}{3} = 1 + 0.5 + 0.333 = 1.833\)
\(\frac{1}{3} = 0.333\) ❌ (No es lo mismo)

Propiedad 9: Suma de constantes variables

Cuando la "constante" depende del índice:

\(\sum_{i=1}^{n} c_i\) (donde \(c_i\) cambia con i)

En este caso, NO podemos factorizar:

\(\sum_{i=1}^{3} i = 1 + 2 + 3 = 6\)
\(3 \times \frac{1+2+3}{3} = 3 \times 2 = 6\) ✅ (Solo en este caso especial)

⚡ Aplicaciones Algebraicas

Manipulación de expresiones complejas

Ejemplo: \(\sum_{i=1}^{5} (3i^2 - 2i + 1)\)

Solución paso a paso:

  1. Separar términos:
    \(\sum_{i=1}^{5} (3i^2 - 2i + 1) = 3\sum_{i=1}^{5} i^2 - 2\sum_{i=1}^{5} i + \sum_{i=1}^{5} 1\)
  2. Calcular cada suma:
    \(\sum_{i=1}^{5} i^2 = 1^2 + 2^2 + 3^2 + 4^2 + 5^2 = 1 + 4 + 9 + 16 + 25 = 55\)
    \(\sum_{i=1}^{5} i = 1 + 2 + 3 + 4 + 5 = 15\)
    \(\sum_{i=1}^{5} 1 = 5 \times 1 = 5\)
  3. Aplicar coeficientes:
    \(3(55) - 2(15) + 5 = 165 - 30 + 5 = 140\)

Verificación manual:

3(1)²-2(1)+1 + 3(2)²-2(2)+1 + 3(3)²-2(3)+1 + 3(4)²-2(4)+1 + 3(5)²-2(5)+1
= (3-2+1) + (12-4+1) + (27-6+1) + (48-8+1) + (75-10+1)
= 2 + 9 + 22 + 41 + 66 = 140 ✅

Propiedad 10: Distributividad general

La distributividad funciona en múltiples términos:

\(\sum_{i=1}^{n} (a_i + b_i + c_i) = \sum_{i=1}^{n} a_i + \sum_{i=1}^{n} b_i + \sum_{i=1}^{n} c_i\)

Ejemplo:

\(\sum_{i=1}^{3} (i + 2i + 3i) = \sum_{i=1}^{3} i + 2\sum_{i=1}^{3} i + 3\sum_{i=1}^{3} i\)
\(6 + 2(6) + 3(6) = 6 + 12 + 18 = 36\)

🔬 Aplicaciones en el Cálculo

¿Por qué la linealidad es crucial?

La propiedad de linealidad es fundamental porque:

  • Simplifica integrales definidas - Las mismas reglas aplican a ∫
  • Permite integración por partes - Base para técnicas avanzadas
  • Facilita series de Taylor - Esencial para matemáticas superiores
  • Conecta sumas con integrales - Puente hacia el cálculo integral

🔮 Conexión con las Integrales

La linealidad de las sumas se convierte en:

\(\int (f(x) + g(x)) dx = \int f(x) dx + \int g(x) dx\)
\(\int c \cdot f(x) dx = c \cdot \int f(x) dx\)

¡Las propiedades que aprendemos aquí son idénticas en integración!

Ejemplo: Si \(\sum_{i=1}^{n} (2i + 3) = 2\sum i + 3\sum 1\)
Entonces \(\int (2x + 3) dx = 2\int x dx + 3\int 1 dx\)

📋 Resumen de la Sesión

✅ Propiedades de linealidad dominadas:

  • Linealidad principal: \(\sum (a_i + b_i) = \sum a_i + \sum b_i\)
  • Distributividad: \(c \times \sum a_i = \sum (c \times a_i)\)
  • Múltiples términos: \(\sum (a_i + b_i + c_i) = \sum a_i + \sum b_i + \sum c_i\)
  • Coeficientes constantes: \(\sum (c_1 a_i + c_2 b_i) = c_1 \sum a_i + c_2 \sum b_i\)
  • Constante en potencia: \(\sum c^k = k \times c^k\) (potencia constante)
  • Cuidado con fracciones: \(\sum \frac{c}{i} \neq \frac{c}{n}\) (no se puede factorizar)
💡 Conexión con el cálculo: La linealidad de las sumas es idéntica a la linealidad de las integrales. ¡Estamos construyendo los fundamentos del cálculo integral paso a paso!
